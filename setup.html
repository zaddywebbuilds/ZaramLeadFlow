Installation steps

Follow these in order. Takes about 2 minutes.

Step 1
Download & unzip the file
Click the Download ZaramLeadFlow button above. You’ll get a .zip file.

Once downloaded, right-click the zip file and choose “Extract All” (Windows) or double-click it (Mac). This creates a folder called ZaramLeadFlow-Package.

Remember where you save this folder — you’ll need it in Step 3.
Step 2
Open Chrome Extensions & turn on Developer Mode
Open Google Chrome. In the address bar at the top, type exactly:

chrome://extensions

Press Enter. You’ll see the Extensions page. In the top-right corner, you’ll see a toggle that says “Developer mode”. Switch it ON (it turns blue).
⚠ You must turn Developer mode ON before the next step will work. The toggle is small — look for it in the top-right of the Extensions page.
Step 3
Load the extension from your folder
Still on the Extensions page, click the button that says “Load unpacked”. A file picker will open.

Navigate to the ZaramLeadFlow-Package folder you extracted in Step 1. Click on the folder to select it, then click “Select Folder” (or “Open” on Mac).
💡 Make sure you select the folder itself, not a file inside it. The folder is called ZaramLeadFlow-Package.
Step 4
Pin it to your Chrome toolbar
You’ll now see ZaramLeadFlow in your extensions list. To make it easy to access, pin it to your toolbar:

Click the puzzle piece icon (⚙) in the top-right of Chrome. Find ZaramLeadFlow in the list and click the pin icon next to it. The ZaramLeadFlow icon will now appear in your Chrome toolbar every time you open Chrome.
Step 5
Enter your license key & start outreach
Click the ZaramLeadFlow icon in your toolbar. The extension side panel will open.

Go to Settings (the gear icon ⚙). Under the License section:

1. Enter the email address you used to pay
2. Paste the license key from your email (starts with ZARAM-...)
3. Click Activate License
🔒 Your license key is in the email that was sent right after payment. Subject line: “Your ZaramLeadFlow License Key”. Check spam if you cannot find it.
Step 6
Add your AI API key
ZaramLeadFlow uses AI to write personalized messages. You need your own API key — it takes 2 minutes to get one for free.

In the extension Settings, find "API Key" and "AI Provider".

Option A — OpenAI (recommended for most users):
1. Go to platform.openai.com/api-keys
2. Sign in (or create a free account)
3. Click “Create new secret key” — give it any name
4. Copy the key (starts with sk-...)
5. In the extension Settings, set AI Provider to OpenAI and paste the key

Option B — OpenRouter (if you want to use Claude / Anthropic models):
1. Go to openrouter.ai/keys
2. Sign in (or create a free account)
3. Click “Create Key”
4. Copy the key (starts with sk-or-v1-...)
5. In the extension Settings, set AI Provider to OpenRouter and paste the key
💰 Both OpenAI and OpenRouter charge per message generated — typically less than $0.01 per message. You only pay for what you use. A free-tier OpenAI account gives you enough credits to get started.
🔒 Your API key is stored only in your browser and sent directly to OpenAI/OpenRouter. It never touches anyone else’s server permanently. Keep it private — do not share it.
🎉

You’re all set!

ZaramLeadFlow is installed and activated. Import your first Google Sheet or CSV and start sending personalized DMs today.
